# FPS Shooter & Action Game — studio website

Public developer website for the Google Play account
[FPS Shooter & Action Game](https://play.google.com/store/apps/dev?id=6291860569891816067).

Served by GitHub Pages at the repository's root domain so that `app-ads.txt`
is reachable at `/app-ads.txt`, as required by AdMob authorized sellers.

| Path | Purpose |
|---|---|
| `index.html` | Games, screens, studio, support & contact |
| `support.html` | Contact details, response-time commitments, common fixes |
| `refund-policy.html` | Refund policy for in-app purchases |
| `privacy-policy.html` | Privacy policy (ads, analytics, data rights) |
| `terms.html` | Terms of service |
| `app-ads.txt` | AdMob / mediation authorized sellers (must stay at root) |

No build step. Edit the HTML and push.
